# Template Studio Web Mobile V108

Mobile-first refinement of V107. Existing editor features are preserved.

Mobile improvements:
- Compact top bar for small screens
- Horizontal scrollable bottom tool bar for touch devices
- Larger touch targets for Properties controls
- Safe-area support for phones with gesture/navigation areas
- Canvas remains pinch-to-zoom and one-finger pan on empty canvas after zoom
- Existing V107 background color, gradient controls, free bars, layers, fonts and export remain
